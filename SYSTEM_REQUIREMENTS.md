# System requirements

## Supported Windows setup

- Windows 10 or Windows 11
- Python 3.11, 3.12, or 3.13 with the standard `sqlite3` module
- A current Chromium-, Firefox-, or WebKit-based desktop browser
- 200 MB of free disk space for the application, saves, logs, backups, and support exports
- A writable extracted project folder

No administrator access, account, API key, firewall change, or internet connection is required.

## Other operating systems

The Python entry point and hosted CI exercise source portability beyond Windows. The Windows batch launchers and platform-specific acceptance checks remain Windows-specific.

## Accessibility

The interface includes keyboard navigation, visible focus, reduced-motion and high-contrast support, responsive layouts, and reading-focused presentation. Formal screen-reader certification and broad human usability studies are not claimed.
